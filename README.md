# AI Projects

My AI/ML projects, built while learning. Every folder is a separate project with its own README — what it does, the results, and how to run it.

## Machine Learning

- **[Flight Delay Predictor](Machine_Learning/ML_Flight_Delay_Predictor)** — end-to-end app (Streamlit + FastAPI + XGBoost) that predicts whether a flight will arrive 15+ minutes late
- **[Loan Prediction System](Machine_Learning/ML_Loan_prediction_system)** — two-stage Random Forest: first loan approval, then the amount. Streamlit app + FastAPI

## Deep Learning

- **[TwinTalk — Transformer Language Model](Deep_Learning/Transformer_Language_model)** — a decoder-only transformer built from scratch in PyTorch, trained on chat data, with a Streamlit chat app
- **[ANN — Bank Churn Prediction](Deep_Learning/ANN_Churn_Prediction)** — Keras ANN predicting which bank customers will leave (test accuracy 0.85)
- **[CNN — MNIST Image Classification](Deep_Learning/CNN_Image_classification)** — a plain network vs a CNN on handwritten digits (93.77% → 98.77%)
- **[RNN — Music Generation](Deep_Learning/RNN_Music-Generation)** — character-level LSTM that generates music in ABC notation
- `PyTorch_fundamentals.ipynb` — PyTorch basics practice (tensors, autograd, first models)
