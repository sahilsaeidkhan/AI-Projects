# AI Projects

These are the AI/ML projects I have built while learning. Each project folder has its own README with the details and results.

## Machine Learning

- **[Flight Delay Predictor](Machine_Learning/ML_Flight_Delay_Predictor)**: predicts if a flight will arrive 15+ minutes late. Streamlit UI, FastAPI and XGBoost.
- **[Loan Prediction System](Machine_Learning/ML_Loan_prediction_system)**: two-stage Random Forest. First it predicts approval, then the loan amount. Has a Streamlit app and a FastAPI API.

## Deep Learning

- **[TwinTalk](Deep_Learning/Transformer_Language_model)**: a small GPT-style transformer I built from scratch in PyTorch and trained on chat messages. Comes with a Streamlit chat app.
- **[ANN Churn Prediction](Deep_Learning/ANN_Churn_Prediction)**: Keras ANN that predicts which bank customers are about to leave. Test accuracy 0.85.
- **[CNN MNIST](Deep_Learning/CNN_Image_classification)**: handwritten digit classification. A plain network got 93.77%, the CNN got 98.77%.
- **[RNN Music Generation](Deep_Learning/RNN_Music-Generation)**: character-level LSTM that writes music in ABC notation.
- `PyTorch_fundamentals.ipynb`: my PyTorch basics practice (tensors, autograd, small models).

## NLP

- **[NLP Practice](NLP)**: NLTK and spaCy basics. Tokenization, stemming, lemmatization, POS tagging, NER.
